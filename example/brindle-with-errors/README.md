# Brindle

Brindle is a fictional recipe-sharing service. Cooks publish recipes, follow
each other and export a weekly shopping list. This folder is a made-up project
used to demonstrate `verify_index.py`. Nothing here describes a real product.

Stack (invented): a Python API, a SQLite file per tenant, a small web client.

Start with `docs/architecture.md`, then `docs/api.md`.
